# Volleyball Team Generator

A Streamlit-based web app that generates fair, balanced volleyball teams based on player positions and skill levels using the OpenAI API.

Built to solve a real problem for recreational volleyball groups — removing the guesswork and bias from team selection.

## Features

- CSV upload or manual player entry via form
- AI-generated balanced teams based on position and skill
- Session management and dynamic UI interactions
- Object-oriented architecture with modular components (PlayerManager)
- Form validation and error handling
- Unit testing via `streamlit.testing`

## Tech Stack

**Language:** Python  
**Framework:** Streamlit  
**AI:** OpenAI API  
**Testing:** streamlit.testing  
**Tools:** Git, Docker

## Getting Started

```bash
# Clone the repository
git clone https://github.com/JeiHyde25/volleyball-team-generator.git
cd volleyball-team-generator

# Install dependencies
pip install -r requirements.txt

# Add your OpenAI API key
export OPENAI_API_KEY=your_key_here

# Run the app
streamlit run app.py
```
